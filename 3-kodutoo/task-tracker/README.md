# Task Tracker

Task Trackeri frontend (React + Vite). Taskid tulevad backendist (`task-tracker-api`).

## Käivitamine

Enne käivita backend (`task-tracker-api` kaustas `npm start`).

```bash
npm install
npm run dev
```

Ava link, mis terminalis tuleb (nt http://localhost:5173/task-tracker/).

Backendi aadress on vaikimisi http://localhost:3000.

## Käsud

- `npm run dev` – arendusserver
- `npm run build` – build kausta `dist`
- `npm test` – testid
- `npm run format` – Prettier
